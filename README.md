# 🤖 CodeGuru – AI-Powered Code Explanation Tool

Welcome to **CodeGuru**! 🧠✨  
This project uses the OpenAI API to explain Python code in simple, human-friendly language.

---

## 🚀 Features

- 📝 Paste any Python code
- 🤖 Get detailed, plain-language explanations
- 🌐 Simple web interface built with Flask
- 🔐 Environment-safe with `.env` support

---

## 🔧 Tech Stack

- 🐍 Python
- 🌐 Flask
- 💡 OpenAI GPT API
- 📦 python-dotenv
